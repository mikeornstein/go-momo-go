## Known defects

- `walk-slice.png` walker head reads as a void helmet. Chevron jacket, fist, hydrant, three-band stage, and this Momo are the lock.
- `gnome-bumper.png` lawn is still a green tint. Gnome face + matching stipple doodle are the lock. Do not replace with a 2×2 checker hedge.
- Stipple must stay locked to the sprite (not a 2×2 that strobes).
- Engine art FatBits-cleans outlines to a true 3 px cel.
